# Resolução exercício Beecrowd1003

## Descrição do problema
Leia dois valores inteiros, no caso para variáveis A e B. A seguir, calcule a soma entre elas e atribua à variável SOMA. A seguir escrever o valor desta variável.

## Como Funciona
1. O usuário insere dois números inteiros, que são armazenados nas variáveis `A` e `B`.
2. O código realiza a operação aritmética de adição entre os dois valores (`A + B`).
3. O resultado calculado é atribuído à variável `SOMA`.
4. O programa imprime o resultado no console com o formato padrão: `SOMA = [resultado]`.
